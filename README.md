# paradigmaUAP2026
Repo de paradigma UAP 2026

Se rinden 2 parciales y se tiene la posibilidad de recuperar.  

# Condición: 
Regular: Promedio de los parciales igual o mayor a 60% y ningún examen menor a 50%.
Promoción: Promedio de los parciales igual o mayor a 70%, ningún examen menor a 65%. 
En caso contrario, libre. 

El curso se regularizará o promocionará con 2 tp aprobados.
